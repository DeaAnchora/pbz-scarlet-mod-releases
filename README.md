请到 [Releases](https://github.com/DeaAnchora/pbz-scarlet-mod-releases/releases) 下载完整 ZIP。当前红莲主包为 **[V11.1.3 测试版](https://github.com/DeaAnchora/pbz-scarlet-mod-releases/releases/tag/v11.1.3)**。黑伤LB+Y已获用户确认，新增LT独立特效适配仍待实测，其它武器技能及整体稳定性仍在修复与验收。

GitHub 自动生成的 Source code ZIP/TAR 仅包含本仓库文档；安装 Mod 请下载 Release 附件中名称带 `v11.1.3.zip` 的完整包。

## 迅驰模式（独立模块）

**[迅驰模式 V9.0.9 完整测试版](https://github.com/DeaAnchora/pbz-scarlet-mod-releases/releases/tag/swift-v9.0.9)** · [下载完整 ZIP](https://github.com/DeaAnchora/pbz-scarlet-mod-releases/releases/download/swift-v9.0.9/PBZ-Swift-Mode-v9.0.9-full.zip) · [安装、快捷键与回退说明](docs/Swift-Mode-V9.0.9.md)

迅驰是红莲角色的可选附加模块，需要先安装红莲主包；目前识别白旗袍和毛衣两套已审核外观。默认关闭，按 **F10** 或同时点按 **LB + RB** 切换。其它人物或服装不在当前适用范围。

迅驰包独立提供全部模块资源、UE4SS运行文件及完整`Mod文件/UE4SS-FirstInstall/`，保持安装.cmd、卸载.cmd、快捷键设置.lua、说明.txt、Mod文件五项外层。安装/卸载均须先完全退出游戏，回执支持精确回退；不会默认并入红莲主包。

本次发布保持当前迅驰23项模块内容原字节，仅整理完整安装、校验和回退。发布状态为测试版，离线验包与回退通过不代表所有实机场景已通过。下载Release附件，不要将GitHub自动生成的Source code归档当成安装包。

## 安装

完全退出全部 PBZ 游戏进程后，解压完整包并运行“安装.cmd”，按提示选择游戏根目录。安装器会校验载荷、检查游戏是否退出并保存精确备份。已有用户快捷键、共享框架及无关 Mod 按安装策略保留。

公开外层固定为五项：

```text
影境转生红莲大人，开局遇见理智孽奇拔/
├─ 安装.cmd
├─ 卸载.cmd
├─ 快捷键设置.lua
├─ 说明.txt
└─ Mod文件/
```

完整 UE4SS 运行文件与原目录 `Mod文件/UE4SS-FirstInstall/` 已包含；FirstInstall 共8个文件。请保持整包结构。

## 精确回退

运行“卸载.cmd”，或使用本次游戏目录 `ModBackups/ScarletV11103/` 回执备份内的“回退到安装前.cmd”。回退前同样须完全退出游戏。

从11.1.2升级时核对93项基线、精确备份并替换3个既有文件、新增1项独立技能模块，其余90项路径保持。独立回退助手在候选目录移走后仍能恢复原3文件并移除新增项。支持完整首次安装；其它现有版本或未知手工修改会触发保护。
