# 影境转生红莲大人，开局遇见理智孽奇拔 V12.0.1

《影之刃零》（PBZ）红莲角色Mod、星刃外观适配，以及迅驰模式。

本测试版处理角色替换后的重复布料开销：当红莲外观生效，且原角色的头发、上衣、裙子或披风布料已经隐藏时，暂停对应原布料组件的模拟。红莲本身的头发、裙摆、袖子和背部飘带继续使用原有动态设置。

只处理当前玩家身上符合指定资源路径的原布料组件。组件所有者、当前角色外观、隐藏状态和所需接口均核对后才会执行；已经暂停的组件保持原状。保留角色动画更新、面部驱动、武器、技能和现有快捷键。

此版本尚未完成游戏帧时间对照，实际收益会随原布料组件是否启用及场景负载而变化。暂停隐藏组件不能保证所有情况下的帧率提升。

完全退出游戏后运行“安装.cmd”，选择PBZ游戏目录。使用完整安装包，保留“Mod文件”目录。已安装过本模组时，安装器会核对原版本、备份需要替换的文件，并生成独立回退工具；不要手动覆盖旧版或删除备份。

首次安装包含完整UE4SS框架及首次安装目录，按安装器提示操作。快捷键设置位于“快捷键设置.lua”，原有自定义设置会按安装器规则保留。

需要回退时，完全退出游戏后，运行本次安装备份目录中的“回退到安装前.cmd”。卸载使用“卸载.cmd”。请保留安装器返回的备份目录。

## 升级说明

本包支持首次安装和受支持的V11.2.4升级。使用V12.0.0或其它旧版时，请先完全退出游戏，使用对应旧包的卸载入口，再安装本版，并保留旧备份和个人快捷键配置。遇到基线不匹配提示，请勿强制覆盖。

## 已知问题

复杂动作下的衣物避让、部分武器独立技能特效及长期稳定性仍在完善。此版本继续作为测试版提供；尚未完成新版游戏帧时间对照，不提供固定帧率提升承诺。
