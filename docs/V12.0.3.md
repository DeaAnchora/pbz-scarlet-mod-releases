# 影境转生红莲大人，开局遇见理智孽奇拔 V12.0.3

《影之刃零》（PBZ）红莲角色Mod、星刃外观适配，以及迅驰模式。

本包是红莲角色与星刃外观适配的完整测试版；迅驰模式单独下载、安装。

## 本版更新

- 相较 V12.0.1，减少无关动画事件的回调处理，并修正过场和装备预览的外观筛选。
- 跳过保存在序列资源中的角色模板，减少无效换装准备和组件遍历；实际过场角色、装备预览及外观切换继续使用原有路径。
- 保留现有头发、裙摆、袖子和背部飘带动态，以及材质、动画和武器技能内容。
- 延续隐藏原角色布料的暂停处理，提供完整安装、首次安装运行文件和独立回退。

默认旗袍，按 N 循环切换旗袍、休闲针织裙装和优雅裙装。快捷键可在“快捷键设置.lua”中调整。

## 安装与升级

1. 完全退出游戏，解压完整 ZIP，保留全部目录结构。
2. 将解压后的完整 Mod 文件夹放入 PBZ 游戏根目录，与 `platform`、`ProjectPBZ` 同级，再运行文件夹中的“安装.cmd”。
3. 首次安装所需 UE4SS 文件及完整 `Mod文件/UE4SS-FirstInstall/` 已包含，无需从旧包补文件。

本包支持首次安装及受支持的 V12.0.2 升级。使用 V12.0.1、V12.0.0 或其它旧版时，请先使用对应旧包的卸载入口，再安装本版，并保留旧备份和个人快捷键配置。遇到基线不匹配或文件冲突提示，请勿强制覆盖。

安装和独立回退继续支持本地根目录联接、符号链接及系统卷挂载入口。请保持完整的五项外层内容：“安装.cmd”“卸载.cmd”“快捷键设置.lua”“说明.txt”和“Mod文件”。

## 卸载与回退

退出游戏后运行“卸载.cmd”，或使用本次备份目录中的“回退到安装前.cmd”。本版备份位于游戏根目录 `ModBackups/ScarletV12003/`，请保留整个备份目录；移走安装包后仍可使用备份内的独立入口。

## 已知限制

持续卡顿的主要开销仍在调查，本版尚未完成同条件游戏帧时间对照，不承诺固定帧率提升。复杂动作下的衣物避让、部分武器独立技能特效及长期稳定性仍在完善，因此继续作为测试版提供。

安装器和独立回退已在 PowerShell 7 与 Windows PowerShell 5.1 中核验；新版过场、预览表现及性能收益仍需要更多实机反馈。
