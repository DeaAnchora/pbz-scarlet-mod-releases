# 影境转生红莲大人，开局遇见理智孽奇拔 V11.1.3（测试版）

## 本版变化与验收范围

- 黑伤LB+Y强化红光已获用户实机确认，本版保留已通过的实现与专用资源。
- 新增黑伤独立BladeBuff技能特效的空间适配，针对LT反馈的剑下方红黑特效。依据原黑伤剑身起点、剑尖和星刃实际刀面几何建立私有视觉坐标，保留原粒子模板、材质、模拟程序、激活、池化、持续时间、消退及返回组件。LT最终像素贴合仍待用户测试。
- 保留11.1.2已实机记录ready与强化映射的远跳转桥接，以及动画钩子独立Lua状态、收拔刀和有条件过场恢复。桥接DLL保持11.1.2原字节，模块日志中的版本标识仍为11.1.2。
- 补充检查40份武器配置、2436份已保存能力/动画元数据节点和100个独立GameplayCue包，识别15条武器来源组件记录、14个显式不同系统。其它武器的独立网格、特殊挂点及组件材质分支仍在逐项修复，未宣称全武器或全技能完成。

持续战斗稳定性、LT及其它技能最终视觉、过场恢复和CPU性能尖峰改善尚未整体验收；本Release发布为测试版。

## 安装与精确回退

完全退出全部PBZ游戏进程，解压完整包并运行安装.cmd，选择游戏根目录。安装器自动检查载荷、游戏状态、现有文件与安装前基线；已有用户配置、共享框架和无关Mod按安装策略保留。

本版支持完整首次安装及受管11.1.2基线升级。从11.1.2升级时先核对93项基线，精确备份三个原文件，再替换主模块元数据与两项特效Lua，新增一个独立技能Lua，其余90项路径保持。未知版本或手工修改触发保护，不强制覆盖。

安装回执在游戏根目录ModBackups/ScarletV11103/内；卸载.cmd或本次回执目录的回退到安装前.cmd可精确恢复安装前字节并移除本次新增项。独立助手和94路径安装前快照保存在回执目录，原下载包移走后仍可回退；回退前同样需完全退出游戏。所有旧回退链保留。
