# 影境转生红莲大人，开局遇见理智孽奇拔 V11.1.3（测试版）

这一版继续完善星刃的技能特效，重点处理黑伤强化红光与LT独立红黑特效。其它武器的部分独立特效和持续战斗稳定性仍在完善中，欢迎反馈具体复现情况。

## 更新内容

- 黑伤LB+Y强化红光适配星刃刀身。
- 新增黑伤LT独立红黑特效适配，调整它相对星刃的位置和方向，保留原粒子、材质和技能时序。
- 保留V11.1.2的特效桥接，以及动画与特效回调隔离处理。
- 保留收拔刀、外观切换和过场后的武器恢复处理。
- 继续检查其它武器的独立附刃、特殊挂点和组件特效，后续逐项更新。

## 已知问题

- LT特效的最终贴合效果仍需在不同动作下继续测试。
- 其它武器尚有未适配的独立技能特效，可能保留原武器形状或出现偏移。
- 持续战斗、过场后的武器显示与性能尖峰仍需继续观察；本版不作为稳定版发布。

外层为`安装.cmd`、`卸载.cmd`、`快捷键设置.lua`、`说明.txt`、`Mod文件/`五项，请保持完整。
