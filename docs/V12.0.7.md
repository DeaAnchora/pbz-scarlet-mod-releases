# 红莲 V12.0.7 完整测试版

《影之刃零》（PBZ）红莲角色Mod、星刃外观适配，以及迅驰模式。

## 相较 V12.0.3 的更新

- 修正优雅裙装紫色领结后方的颈身接缝，头部和脖子沿用胸口的肤色。
- 柔化双颊的细碎纹理，将细小高光集中在鼻尖和下唇。人物沿用原有站姿和手位。
- 调整三套衣装的皮肤材质。换装或换图后继续识别新出现的原角色部件，已隐藏、已暂停的部件会跳过重复处理。

不同场景的光照会影响肤色和高光的观感。复杂动作下的衣物穿插及部分武器技能特效仍在完善。

## 安装与换装

本包支持首次安装，也支持从文件与基线一致的 V12.0.6 直接升级。正在使用上一公开版 V12.0.3 或其他旧版的玩家，请保留备份及个人快捷键配置，先用对应旧版本的卸载入口卸载，再安装 V12.0.7。

1. 退出游戏，下载并完整解压 `PBZ-Scarlet-v12.0.7-full.zip`。
2. 将解压后的整个 Mod 文件夹放进游戏根目录，与 `platform` 和 `ProjectPBZ` 同级。进入 Mod 文件夹，运行 `安装.cmd`。
3. 安装完成后进入游戏。默认穿旗袍，按 **N** 依次切换到休闲针织裙装、优雅裙装。可以在 `快捷键设置.lua` 中改键。

包内包含首次安装所需的 UE4SS 文件。迅驰模式单独下载、安装。
