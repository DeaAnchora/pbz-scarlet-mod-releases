# 迅驰模式 V9.0.9（测试版）

[发布页](https://github.com/DeaAnchora/pbz-scarlet-mod-releases/releases/tag/swift-v9.0.9) · [下载完整ZIP](https://github.com/DeaAnchora/pbz-scarlet-mod-releases/releases/download/swift-v9.0.9/PBZ-Swift-Mode-v9.0.9-full.zip)

迅驰是我为红莲角色提供的可选外观模式，需要先安装红莲主包。目前支持白旗袍和毛衣外观，单独下载、安装，不会随红莲主包默认启用。

## 操作与适用范围

- 默认关闭，按**F10**或同时点按**LB+RB**切换。
- 退出迅驰模式后恢复原外观。
- 当前只支持白旗袍和毛衣两套红莲外观，其它人物或服装不在支持范围内。

## 安装

1. 先安装红莲主包，然后完全退出游戏。
2. 解压迅驰完整包，保持目录结构。
3. 运行`安装.cmd`，按提示选择PBZ游戏根目录。
4. 启动游戏后使用快捷键切换。

```text
迅驰外观/
├─ 安装.cmd
├─ 卸载.cmd
├─ 快捷键设置.lua
├─ 说明.txt
└─ Mod文件/
```

包内包含全部迅驰模块资源、UE4SS运行文件和完整的`Mod文件/UE4SS-FirstInstall/`，不需要从旧版补文件。红莲角色资源仍由红莲主包提供。

安装器会检查文件完整性、游戏状态和已有文件，并保存安装前备份。已有配置、共享框架和其它Mod会按安装规则保留；出现文件冲突提示时，请保留提示信息并反馈，不要强制覆盖。

## 修改快捷键

首次安装前，可在包外层`快捷键设置.lua`中修改`keyboardKey="F10"`，保留其它代码。

已安装时，安装器会保留现有入口配置；请在完全退出游戏后，修改游戏目录`platform/steam/ue4ss/Mods/PBZSwiftMode/Scripts/main.lua`中的同一项，下次启动生效。手柄默认同时点按LB+RB。

## 卸载与回退

完全退出游戏后运行`卸载.cmd`，或使用游戏根目录`ModBackups/SwiftV909/`下本次备份内的`回退到安装前.cmd`。

回退恢复安装前文件并移除本次新增内容；共享框架、已有配置与其它Mod按回退规则保留。移走原安装包后仍可使用备份内的独立入口，请保留备份目录。文件被手动修改或备份损坏时会停止操作。
