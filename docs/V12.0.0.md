# 影境转生红莲大人，开局遇见理智孽奇拔 V12.0.0（测试版）

V12整合红莲角色、星刃外观适配和优雅裙装的近期更新。包含旗袍、毛衣、优雅裙装三套外观；默认旗袍，按N依次切换，也可在快捷键配置中调整。

## 本版内容

- 恢复优雅裙装，调整裙身织物光泽与花纹层次，改善塑料反光。
- 袖子与背部飘带分别设置纱质透感，背部飘带略显厚实。
- 改进左右大腿与裙摆的动态避让，调整裙片弯折约束与物理计算设置，保留柔性裙摆及背部飘带。
- 保留黑伤、冰火、风雷、乱萤和左手天邈的既有星刃特效适配，以及收拔刀和过场后的武器恢复处理。

V12.0.0的角色、材质、物理及技能内容沿用V11.2.4。本次统一主版本号并提供完整安装包。

## 安装与快捷键

1. 完全退出游戏。
2. 解压完整ZIP，保持全部文件与目录结构。
3. 将解压后的完整Mod文件夹放入PBZ游戏根目录，与`platform`、`ProjectPBZ`同级，再运行Mod文件夹内的`安装.cmd`。
4. 安装完成后启动游戏。按N切换外观，其它快捷键见`快捷键设置.lua`。

外层固定五项：`安装.cmd`、`卸载.cmd`、`快捷键设置.lua`、`说明.txt`、`Mod文件/`。包内包含UE4SS运行文件和完整的`Mod文件/UE4SS-FirstInstall/`，不需要从旧包补文件。

支持首次安装和受支持的V11.2.4升级。其它旧版建议先使用对应旧包的卸载入口，再安装本版；请先保留旧备份和个人配置。安装器会校验文件、检查游戏状态并保存安装前备份，已有配置按规则保留。遇到版本或文件不匹配提示，请保留提示信息并反馈，不要强制覆盖。

安装与独立回退支持游戏根目录及上级的本地目录联接、符号链接和系统卷挂载入口，并核验实际目录身份。游戏内部受管路径单独重定向会拒绝。Windows PowerShell5.1遇到过长的备份路径会在写入前提示。

## 卸载与回退

完全退出游戏后运行`卸载.cmd`，或使用游戏根目录`ModBackups/ScarletV12000/`下本次备份内的`回退到安装前.cmd`。回退恢复安装前文件并移除本次新增项。请保留完整备份目录，移走下载包后仍可使用其中的独立回退入口。手工改动或备份损坏会触发保护。

## 已知问题与反馈

本版仍为测试版。复杂攻击、转向和极端姿势下的裙摆避让及飘带运动仍需继续测试；材质观感随光照变化。物理细化可能增加计算开销，低帧率及持续战斗性能仍在观察。

部分武器的独立技能特效仍未完成适配，持续战斗稳定性和性能尖峰继续完善。遇到问题请附版本、外观、武器、操作步骤、截图或对应时间的日志。

迅驰模式为单独提供的可选模块，不随本包安装或启用。UE4SS原始许可证随包保留。
