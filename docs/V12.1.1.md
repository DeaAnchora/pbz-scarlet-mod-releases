# 红莲 V12.1.1 完整测试版

《影之刃零》（PBZ）红莲角色Mod、星刃外观适配，以及迅驰模式。

## 相较 V12.0.7 的更新

- 双手垂下时，优雅裙装会在手旁局部压低裙边，抬手后释放压痕。调整左右袖口与外裙、侧纱接触的位置，并收整裙摆稳定后容易穿过左手掌的裙边。
- 改善 Boss 转阶段演出后的武器显示。演出结束回到战斗时会重新核对手中武器，覆盖演出前收刀、演出后首次拔刀的情况。
- 沿用原有站姿、手位，以及上一版头颈与胸口统一的肤色和脸部材质。

部分动作中袖口仍可能与裙料接触。Boss 二阶段后的武器恢复已做离线测试，具体演出的游戏内表现仍待确认。

## 安装与换装

本包支持首次安装，也支持从文件与基线一致的 V12.1.0 直接升级。正在使用上一公开版 V12.0.7 或其他旧版的玩家，请保留备份及个人快捷键配置，先用对应旧版本的卸载入口卸载，再安装 V12.1.1。

1. 退出游戏，下载并完整解压 `PBZ-Scarlet-v12.1.1-full.zip`。
2. 将解压后的整个 Mod 文件夹放进游戏根目录，与 `platform` 和 `ProjectPBZ` 同级。进入 Mod 文件夹，运行 `安装.cmd`。
3. 安装完成后进入游戏。默认穿旗袍，按 **N** 依次切换到休闲针织裙装、优雅裙装。可以在 `快捷键设置.lua` 中改键。

包内包含首次安装所需的 UE4SS 文件。迅驰模式单独下载、安装。
