# 影境转生红莲大人，开局遇见理智孽奇拔 V11.1.7（测试版）

本版补充乱萤鸣剑及双剑强化的右手附刃特效适配，将两套强化效果中的旧剑形网格替换为星刃对应几何，并对齐右手星刃。保留原来的粉色材质、粒子程序、持续时间和消退时序；此前左手天邈的出场特效与二阶段刀光适配继续保留。

黑伤、冰火、风雷的既有适配，以及收拔刀和过场后的武器恢复处理保持不变。其它形态和武器的部分独立特效仍在完善中；持续战斗稳定性仍需进一步测试。

## 安装

完全退出游戏，解压完整ZIP，运行`安装.cmd`，按提示选择PBZ游戏根目录。

外层固定五项：`安装.cmd`、`卸载.cmd`、`快捷键设置.lua`、`说明.txt`、`Mod文件/`。包内包含UE4SS运行文件和完整的`Mod文件/UE4SS-FirstInstall/`，不需要从旧包补文件。

安装与回退支持游戏根目录的本地联接、符号链接和系统卷挂载入口，并核验实际目录身份；游戏内部受管路径的单独重定向仍会拒绝。Windows PowerShell5.1遇到过长的备份路径会在写入前停止并提示。

支持首次安装及受支持的V11.1.6升级。安装器会校验已有文件、保留配置并先保存备份。若提示版本或文件不匹配，请保留提示信息，不要强制覆盖。

## 卸载与回退

完全退出游戏后运行`卸载.cmd`，或使用游戏根目录`ModBackups/ScarletV11107/`下本次备份内的`回退到安装前.cmd`。

回退会恢复本次安装前的文件，并移除本次新增内容。请保留备份目录，移走安装包后仍可使用备份内的独立入口。文件被手动修改或备份损坏时，回退会停止，避免覆盖改动。
