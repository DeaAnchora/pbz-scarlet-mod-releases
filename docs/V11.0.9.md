# 影境转生红莲大人，开局遇见理智孽奇拔 V11.0.9（测试版）

本版针对战斗崩溃转储中确认的特效/动画钩子共享 Lua 栈关系进行隔离。动画工作线程回调迁移到独立 `ScarletAnimationHooks` LuaMod，主模块移除其注册；框架参数包装开始前就有独立状态。原动画处理函数正文逐字节保留。

新增两类回调首次执行的 `ScarletHookIsolation` 身份记录，可核对 registry 与 hook_thread 不同。成功注册后取消独立模块的注册重试任务。UE4SS DLL、Rig、原资源、技能数值与时序不变。

保留 V11.0.8 的破军普通/强击/蓄力刀光、黑伤LB+Y专用强化网格、收拔刀及有条件过场恢复。它们的最终视觉和实际过场行为仍待验收。

## 已完成的离线验证

- 匹配版本 LuaRaw 真实C API观察到旧共享栈错误条件；独立状态通过相同受控交错顺序、双线程100000次参数包装、1000次跨状态嵌套，最终栈顶均为0。
- 407项原有运行回归及34项新增隔离/动画检查通过。
- PowerShell7和Windows PowerShell5.1各29项安装/拒绝检查、5组精确回退通过，回退助手各执行8次，包含移走候选目录后的独立回退。
- 最终完整ZIP的96个文件、88项安装载荷逐项读取验哈希；五项外层及完整8文件FirstInstall均通过检查。

这些是离线验证，不等于实际游戏已通过稳定性验收。新LuaMod实际加载、持续战斗、黑伤LB+Y强化、收拔刀及过场恢复仍待实机测试；本Release明确标记为测试版。

## 安装及回退

完全退出游戏后运行安装.cmd。从V11.0.8升级会先校验84项基线，精确备份3个变更文件，再写入3个替换项和4个新增项，保留81项既有载荷。备份目录生成独立回退入口和安装前快照，即使移走下载包仍可恢复原3文件并移除新增4项。

回退及安装均保留用户配置、共享框架、FirstInstall和其它Mod。未知改动或备份损坏会阻止覆盖。回退旧版本不代表旧版本的并发隐患已经根治。
